# نداء (Nidaa) — توثيق استخدام التطبيق

تطبيق **نداء** هو تطبيق جوال للتبليغ عن الطوارئ مبني بلغة **Flutter** مع معمارية **MVC** وإدارة الحالة باستخدام **GetX**، موجه للغة العربية بالكامل (RTL).

> هذا الملف يشرح طريقة تشغيل التطبيق وربطه بالـ Backend، وهو مخصص لمن سيستلم المشروع من الـ GitHub.

---

## 1. عن التطبيق

نداء يسمح للمستخدم بـ:

| الميزة | الوصف |
|---|---|
| 🚨 **استغاثة بضغطة واحدة** | زر استغاثة كبير: **ضغطة واحدة** = استغاثة فورية (عد تنازلي 5 ثوانٍ قابل للإلغاء ثم إرسال الموقع وجهات الطوارئ) — **ضغط مطول (1.5 ث)** = تقديم بلاغ كامل (متطلب 4.2) |
| 🗂️ **7 أنواع طوارئ** | إسعاف / حريق / شرطة / إنقاذ / كارثة طبيعية / انهيار مبنى / ازدحام أو إغلاق طرق (4.2) |
| 🎯 **4 مستويات خطورة** | حرج / مرتفع / متوسط / منخفض (4.2) |
| 🧮 **عدد المتضررين** | حقل اختياري لعدد المصابين/المتضررين تقريباً (4.2) |
| 🎙️ **بلاغ صوتي** | تسجيل وصف صوتي + تحويل تلقائي إلى نص (Whisper) يعرض للمراجعة قبل الإرسال، والملف الصوتي يُرفق مع البلاغ (4.3) |
| 🛰️ **تتبع حي للبلاغ** | الجهة المستجيبة + الزمن المتوقع للوصول + مصداقية البلاغ + تقدم المعالجة + خريطة حية، مع إشعار فوري عند تغيّر الحالة (4.4) |
| 🔔 **تنبيهات فورية** | تنبيهات تحذيرية (طقس/كوارث/إغلاق طرق...) تظهر أعلى الرئيسية مع إشعار محلي + **شاشة قائمة كاملة** من أيقونة الجرس (4.5) |

| 👁️ **وضع الشاهد** | "أنا شاهد — إبلاغ سريع": إرسال الموقع بضغطة واحدة دون تفاصيل، مع خيار إرفاق صورة من الموقع قبل الإرسال (4.8) |
| 📴 **وضع أوفلاين** | عند غياب الاتصال يُحفظ البلاغ محلياً مع صورة/صوت ويُرسل تلقائياً عند عودة الشبكة + شريط حالة (4.9) |
| ♿ **الإتاحة** | تكبير الخط (×1.25) وتباين عالٍ لذوي الاحتياجات الخاصة — مبدّلان في حسابي (7.4) |
| 📴 **توفير البيانات** | مبدّل في حسابي يقلل استهلاك البيانات في الطوارئ: ضغط الصور (جودة 40 بدل 80) والصوت (48kbps بدل 128kbps) وتخفيف استطلاع التنبيهات إلى 5 دقائق والبلاغات إلى 30 ثانية (4.9) |
| 🔐 **تخزين مشفّر** | التوكنات والبطاقة الطبية مشفّرة على الجهاز (Keystore) — متطلب 7.2 |
| 🌐 **لغتان** | عربية (RTL) وإنجليزية (LTR) — تبديل من حسابي ويُحفظ (7.4) |
| 📝 **رفع بلاغ** | 7 فئات + 4 مستويات خطورة + وصف + صورة + صوت + عدد المتضررين — كل الحقول اختيارية |
| 📋 **بلاغاتي** | قائمة البلاغات مع فلترة (الكل/قيد المعالجة/مغلق) وتحديث تلقائي كل 6 ثوانٍ |

| 🔐 **مصادقة برقم الهاتف** | تسجيل الدخول برقم الجوال + رمز تحقق (OTP) عبر 6 خانات |

## 2. وضع التشغيل

التطبيق يعمل بوضعين:

- **بدون خادم** (`baseUrl` فارغ في `app_config.dart`): التطبيق يعمل بالوضع المحلي (Mock) — تسجيل الدخول يعمل برمز تحقق **وهمي** يولّده "الخادم المموّه" داخل التطبيق ويطبعه في **لوق الكونسول** (`MOCK SERVER | OTP code: 739102`) بدل إرسال SMS؛ أدخل الرقم الظاهر في اللوق للتحقق. القوائم (البلاغات، مناطق الخطر، المستشفيات، مراكز الخدمة، مراكز الإيواء، نقاط التجمع، التنبيهات) تبقى **فارغة**. جهات الاتصال تُضاف من شاشة حسابي وتُحفظ محلياً. التوكنات والبطاقة الطبية محفوظة في **تخزين مشفّر** (تُفقد عند حذف بيانات التطبيق). تحويل البلاغ الصوتي إلى نص يُرجع نصاً توضيحياً ثابتاً (لا يوجد Whisper محلي).
- **مع خادم** (تعبئة `baseUrl`): كل البيانات تُجلب من الباك اند — لا يوجد أي شيء ثابت في الكود.

> ملاحظة: أرقام الطوارئ العامة المعروضة في شاشة حسابي أرقام سورية ثابتة: الشرطة `112`، الإسعاف `110`، الإطفاء `113` — وهي المقصودة في التطبيق.

التبديل للوضع الحقيقي يتم بتعبئة سطر واحد فقط — راجع القسم 7.

## 7. الربط بالـ Backend (الأهم)

### 7.1 خطوة واحدة للربط

افتح `lib/core/config/app_config.dart` وعيّن رابط الخادم:

```dart
static const String baseUrl = 'https://your-server.com/api';
```

بمجرد تعبئة الرابط يتحول التطبيق **تلقائياً** من البيانات المحلية إلى الطلبات الحقيقية (HTTP عبر Dio) — بدون أي تعديل آخر.

### 7.2 عقد الـ API المطلوب تنفيذه من جهة الخادم

جميع الطلبات بصيغة JSON. الاستجابة الناجحة: كائن/قائمة JSON مباشرة. الخطأ: `{"message": "وصف الخطأ"}` أو `{"detail": "..."}` أو أخطاء الحقول (`{"field": "..."}`) مع رمز حالة مناسب (400/401/404/5xx).

| العملية | الطريقة والمسار | الجسم (Body) | الاستجابة المتوقعة |
|---|---|---|---|
| طلب رمز التحقق | `POST /auth/otp/request` | `{"phone": "+9639xxxxxxxx"}` | اختيارياً `{"otp": "739102"}` (الخادم يولّد رمزاً وهمياً ويطبعه بلوقه بدل إرسال SMS) |
| التحقق من الرمز | `POST /auth/otp/verify` | `{"phone": "+9639xxxxxxxx", "code": "739102"}` | `{"token": "...", "refreshToken": "...", "user": {"id","name","phone"}}` |
| إرسال استغاثة | `POST /sos` | `{"emergencyType", "latitude", "longitude", "contactPhones": [...]}` | — (الخادم يُشعر جهات الاتصال) |
| قائمة البلاغات | `GET /reports` | — | قائمة بلاغات المستخدم |
| إنشاء بلاغ | `POST /reports` | multipart/form-data: `category, severity, description, victimsCount, isWitness, latitude, longitude` + ملف `image` (اختياري) + ملف `audio` (اختياري) | كائن البلاغ |
| تفاصيل بلاغ | `GET /reports/:id` | — | كائن البلاغ (للتتبع الحي) |
| تحويل صوتي إلى نص | `POST /voice/transcribe` | multipart: ملف `audio` | `{"text": "..."}` — يُعرض للمراجعة قبل الإرسال (4.3) |
| مناطق الخطر | `GET /zones` | — | `{"id","name","boundary":[[lat,lng],...],"cause","safetyInstructions":[]}` |
| المستشفيات | `GET /hospitals` | — | `{"id","name","position":{"lat","lng"},"phone"}` |
| مراكز الخدمة | `GET /centers?lat=..&lng=..` | — | `{"id","name","position":{"lat","lng"}}` |
| مراكز الإيواء | `GET /shelters` | — | `{"id","name","position":{"lat","lng"},"capacity","phone"}` (4.6) |
| نقاط التجمع الآمنة | `GET /safe-points` | — | `{"id","name","position":{"lat","lng"},"description"}` (4.6) |
| التنبيهات الفورية | `GET /alerts` | — | `{"id","title","type","message","severity","created_at"}` (4.5) |
| البطاقة الطبية | `GET /medical-card` | — | `{"bloodType","allergies":[],"chronicDiseases":[],"medications":[],"emergencyContactName","emergencyContactPhone"}` (4.7) |
| تحديث البطاقة الطبية | `PUT /medical-card` | كائن البطاقة أعلاه | كائن البطاقة المحدث |
| تجديد التوكن | `POST /auth/token/refresh` | `{"refresh": "..."}` | `{"token": "..."}` |
| تحديث الملف الشخصي | `PUT /profile` | `{"name": "..."}` | `{"id","name","phone"}` |
| جهات الاتصال | `GET /contacts` | — | `{"id","name","relation","phone"}` |
| إضافة جهة | `POST /contacts` | `{"name","relation","phone"}` | كائن الجهة |
| حذف جهة | `DELETE /contacts/:id` | — | — |

**حقول البلاغ** المتوقعة: `{"id","title","location","status":"urgent|processing|closed","category","severity":"critical|high|medium|low","timeAgo","description","imagePath","audioPath","progressValue","latitude","longitude","created_at","victimsCount","respondingAgency","etaMinutes","credibilityScore","isWitness"}` — التطبيق يحسب نص الوقت النسبي محلياً من `created_at` إن وُجد، وإلا يعرض `timeAgo`. `respondingAgency` و`etaMinutes` و`credibilityScore` اختيارية وتُعرض في شاشة التتبع عند توفرها.

**المصادقة**: التطبيق يرفق التوكن الذي حصل عليه من `/auth/otp/verify` في ترويسة `Authorization: Bearer <token>` مع كل الطلبات اللاحقة. عند استجابة `401` يجرّب تجديد التوكن تلقائياً عبر `/auth/token/refresh` (بالـ `refreshToken` المحفوظ) ويعيد الطلب مرة واحدة؛ وإن فشل التجديد يسجّل الخروج ويعود لشاشة الدخول.

### 7.3 ملاحظات مهمة على العقد

1. **صيغة رقم الهاتف**: التطبيق يحوّل الرقم المحلي `09xxxxxxxx` إلى الدولي السوري `+9639xxxxxxxx` تلقائياً قبل كل طلب — الخادم يتعامل مع الصيغة الدولية فقط.
2. **الـ OTP وهمي (لا يوجد SMS)**: الخادم يولّد رمزاً عشوائياً من 6 أرقام عند `POST /auth/otp/request` ويطبعه في **لوق الخادم** (Console) — الرمز لا يصل كرسالة نصية ولا يُعرض داخل التطبيق، ويُستخدم للتحقق في `POST /auth/otp/verify`. يمكن أن تُرجِع الاستجابة الرمز في حقل `otp` (اختياري — للتشخيص فقط).
3. **حالة البلاغ والتقدم**: شاشة "بلاغاتي" تعرض التقدم الحقيقي عبر استطلاع `GET /reports` كل 6 ثوانٍ — الخادم يجب أن يُحدّث `status` و`progressValue`. البلاغات التي لا تعود في قائمة الخادم تُحذف من القائمة محلياً.
4. **الخريطة**: لا توجد أي إحداثيات ثابتة في التطبيق — الخريطة تفتح على موقع المستخدم، وبيانات المناطق والمستشفيات والمراكز تأتي من `/zones` و`/hospitals` و`/centers` فقط.

## 11. نظام التصميم

- **اللون الأساسي**: `#CC1C2E` (أحمر نداء)
- **الخلفية**: `#F9F5F5` (أبيض دافئ)
- **البطاقات**: أبيض بحواف `#EFE6E6`
- **الخط**: Cairo (عربي محسّن — غير مضمّن بعد، راجع القسم 6)
- **الاتجاه**: يُشتق تلقائياً من اللغة — عربية: RTL، إنجليزية: LTR (7.4)
- **اللغات**: العربية (الافتراضية) + الإنجليزية — مبدّل في شاشة حسابي، الخيار محفوظ — مع `localizationsDelegates` كاملة (مكونات Material الداخلية مترجمة)
- **الإتاحة (7.4)**: تكبير الخط ×1.25 + ثيم تباين عالٍ (خلفية بيضاء نقية) — مبدّلان في حسابي، الخياران محفوظان
- **توفير البيانات (4.9)**: مبدّل في حسابي بجانب الإتاحة — عند تفعيله: الصور بجودة 40، التسجيل الصوتي 48kbps، استطلاع التنبيهات كل 5 دقائق، استطلاع البلاغات كل 30 ثانية — يُطبَّق فوراً دون إعادة تشغيل
